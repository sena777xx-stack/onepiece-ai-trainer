# ONE PIECE CARD AI TRAINER Ver3 正式ルール基礎版

黒黄ティーチ（プレイヤー）対 紫エネル（AI）のスマホ向けPWAです。Ver3では、ターンとバトルを正式ルールの順序に作り直しました。

この版はフォルダを使いません。ZIPを展開し、中のファイルをすべてGitHubリポジトリの一番上へアップロードしてください。

## 手順

1. ZIPを「すべて展開」します。
2. 展開したフォルダを開きます。
3. 中のファイルをすべて選択します。
4. GitHubの `Add file` → `Upload files` を開きます。
5. 選択した全ファイルをアップロード枠へドラッグします。
6. `Commit changes` を押します。

ZIPファイル自体はアップロードしません。ファイル名も変更しないでください。同じ名前の古いファイルは上書きされます。

アップロード後に古い画面が出る場合は、Safariのタブを閉じてから開き直してください。ホーム画面版は一度削除し、Safariからもう一度「ホーム画面に追加」すると確実です。

この簡易版では、`index.html`、JavaScript、カードデータ、CSS、アイコンがすべて同じ場所に置かれる設計です。

## Ver3の正式ルール基礎

- 先攻・後攻、先攻順のマリガン、初手5枚、ライフ配置
- リフレッシュ、ドロー、DON!!、メイン、エンドの各フェーズ
- 先攻1ターン目はドローなし・DON!!1枚、以降はDON!!最大2枚追加
- 両プレイヤーとも自分の最初のターンは攻撃不可
- リーダーまたはレストのキャラクターを攻撃対象に選択
- ブロックステップ、カウンターステップ、ダメージステップ
- 同じパワーでも攻撃成功、ライフ0へのダメージとデッキ0枚で敗北
- キャラクターエリア5枚、ステージ1枚
- 付与DON!!は自分のターン中に1枚につきパワー+1000
- ライフのトリガーを使用する／手札に加える選択
- 未登録のカード効果は試合を止めず、安全にスキップ

現在のカード名と効果はエンジン確認用デモデータです。カード固有効果は `cards.json` と `effect-engine.js` へ段階的に追加できます。

# Ver3.2 黒黄ティーチ画像デッキ版

## Ver3.3 手札・初手確認表示

手札を縦向きカードの横1列表示へ変更しました。左右にスワイプして全カードを確認でき、従来どおり横へ収納できます。初手確認では「この5枚で始めますか？」とキープ・マリガンの間に5枚の画像を表示します。

## Ver3.4 DON!!複数枚付与

リーダーまたはキャラの「DON!!を付与」から、使用可能枚数の範囲で0枚から任意の枚数を選べます。付与済み枚数と使用可能枚数を確認し、選んだ枚数を一度に付与できます。

デッキリストの該当2枚は「闇穴道（OP09-098）」ではなく「黒縄・大竜巻（EB04-059）」へ訂正しました。複数対象とライフ表向き処理を伴う固有効果は、未対応の間は安全にスキップします。

## Ver3.6 ハチノス効果

場のハチノスをタップすると、捨てる手札1枚を画像から選択できます。ハチノスをレストしてデッキ上3枚を表示し、《黒ひげ海賊団》1枚までを手札へ、残りをデッキ下へ移動します。レスト中・手札0枚・効果処理中は使用できません。

## Ver3.7 OP16-080 リーダー効果

AIのアタック時、通常のカウンター選択より先にリーダー効果の確認画面が開きます。手札のトリガーカード1枚と、リーダーまたは《黒ひげ海賊団》のキャラ1枚を画像から選択すると、手札を捨ててアタック対象を変更します。同じ相手ターン中は1回だけ使用できます。相手ターン中に自分のキャラのコストを+1する計算処理も追加しています。

## Ver3.8 デッキ確認画像

デッキ確認画面で表向きにしたカードを画像で表示します。「すべて表向き」にも対応し、裏向き・選択・各ゾーンへの移動操作は従来どおり利用できます。

AIはカード本体のパワー、付与DON!!、一時的なパワーを合計し、対象の現在パワー以上になる場合だけ攻撃します。2000などの低パワーで5000のリーダーへ無意味に攻撃する動作を抑止しました。

練習設定として、自分が攻撃するときも攻撃側の合計パワー以下の対象だけを攻撃先一覧へ表示します。対象がない場合は攻撃処理へ進みません（公式ルールでは低いパワーからの攻撃宣言自体は可能ですが、本アプリでは希望された制限を適用しています）。

## Ver3.9 ライフ公開・トリガー選択

ライフでダメージを受けると、手札へ移動する前にカード画像・名前・効果文を表示します。トリガーを持つ場合は「トリガーを使う」「手札に加える」を選択でき、トリガーがない場合も内容を確認してから手札へ加えます。選択が終わるまでバトルとAIの続きは進みません。

## Ver3.9.1 リーダー効果の手順改善

リーダー効果を2段階の選択画面へ変更しました。STEP 1で捨てるトリガーカードを選択して「次へ」、STEP 2で新しいアタック対象を選択して「確定して捨てる」を押します。操作ボタンは画面下に固定され、確定後はトラッシュ移動の結果を表示します。

## Ver3.10 KO時・トリガー効果

OP16-103 ヴァン・オーガー、OP16-109 ドクQ、OP16-110 バスコ・ショットのKO時効果とトリガーを実装しました。各効果は1枚ドロー後に対象画像を表示し、ヴァン・オーガーは最大1枚へパワー-3000、ドクQはコスト1以下を最大2体KO、バスコ・ショットはコスト6以下を最大1体レストします。「選ばず終了」にも対応しています。

プレイヤー側を黒黄ティーチ（OP16-080）の固定50枚デッキに更新しました。ホーム画面の「黒黄ティーチのデッキを見る」から、採用カード・枚数・カード画像を確認できます。盤面と手札も画像表示に対応し、画像を読み込めない場合は自動的に従来の文字カード表示へ戻ります。

カード画像は外部URLから読み込むため、初回表示にはインターネット接続が必要です。現在はゲームの基本操作と汎用効果処理を優先しており、複雑なカード固有効果は未対応でも安全にスキップされます。
