# ONE PIECE CARD AI TRAINER Ver2.3 かんたんアップロード版

この版はフォルダを使いません。ZIPを展開し、中のファイルをすべてGitHubリポジトリの一番上へアップロードしてください。

## 手順

1. ZIPを「すべて展開」します。
2. 展開したフォルダを開きます。
3. 中のファイルをすべて選択します。
4. GitHubの `Add file` → `Upload files` を開きます。
5. 選択した全ファイルをアップロード枠へドラッグします。
6. `Commit changes` を押します。

ZIPファイル自体はアップロードしません。ファイル名も変更しないでください。同じ名前の古いファイルは上書きされます。

この簡易版では、`index.html`、JavaScript、カードデータ、CSS、アイコンがすべて同じ場所に置かれる設計です。

## Ver2.2の追加機能

- 手札の開閉
- スマホ縦型プレイマット
- デッキ上10枚の確認、複数選択、ドロー、シャッフル
- トラッシュのカード確認と複数選択
- ライフのカード確認と複数選択
- 選択カードを手札、トラッシュ、デッキ上下、ライフ上、場へ移動
- JSON効果エンジンから呼び出せるトリガー処理の基礎

## Ver2.3の追加機能

- 手札を右側から開閉するスライド式ドロワーへ変更
- デッキ確認を上から5枚に変更
- デッキ確認を開いた直後は全カード裏向き
- 個別タップによる表向き／裏向き切り替え
- 「すべて表向き」「すべて裏向き」ボタン
- 表向きカードだけ選択・移動可能
- 上から何枚目かを各カードに表示
