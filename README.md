# ONE PIECE CARD AI TRAINER PWA

## 重要
iPhoneでは、ZIPを開いて `index.html` を直接タップするだけではPWAとして動きません。
PWAはHTTPS上に配置する必要があります。

## 最短の使い方（GitHub Pages）

1. GitHubで新しいリポジトリを作る
2. このフォルダ内のファイルをすべてアップロード
3. Settings → Pages
4. Branchを `main`、フォルダを `/root` にして保存
5. 発行されたURLをiPhoneのSafariで開く
6. Safariの共有ボタン → 「ホーム画面に追加」

## Netlifyでも利用可能
このフォルダをNetlify Dropへアップロードすれば公開URLが発行されます。

## 現在の機能
- スマホ縦画面
- PWAホーム画面追加
- オフライン起動
- AI自動ターン
- EASY / NORMAL / HARD
- カード画像の端末内登録
- 手札、盤面、ライフ、DON!!管理
- 攻撃、レスト、1手戻す、対戦ログ
