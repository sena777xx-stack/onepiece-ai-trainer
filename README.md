# ONE PIECE CARD AI TRAINER Ver2.1 かんたんアップロード版

この版はフォルダを使いません。ZIPを展開し、中のファイルをすべてGitHubリポジトリの一番上へアップロードしてください。

## 手順

1. ZIPを「すべて展開」します。
2. 展開したフォルダを開きます。
3. 中のファイルをすべて選択します。
4. GitHubの `Add file` → `Upload files` を開きます。
5. 選択した全ファイルをアップロード枠へドラッグします。
6. `Commit changes` を押します。

ZIPファイル自体はアップロードしません。ファイル名も変更しないでください。同じ名前の古いファイルは上書きされます。

この簡易版では、`index.html`、JavaScript、カードデータ、CSS、アイコンがすべて同じ場所に置かれる設計です。
