# ONE PIECE CARD AI TRAINER Ver3 正式ルール基礎版

黒黄ティーチ（プレイヤー）対 紫エネル（AI）のスマホ向けPWAです。Ver3では、ターンとバトルを正式ルールの順序に作り直しました。

この版はフォルダを使いません。ZIPを展開し、中のファイルをすべてGitHubリポジトリの一番上へアップロードしてください。

## 手順

1. ZIPを「すべて展開」します。
2. 展開したフォルダを開きます。
3. 中のファイルをすべて選択します。
4. GitHubの `Add file` → `Upload files` を開きます。
5. 選択した全ファイルをアップロード枠へドラッグします。
6. `Commit changes` を押します。

ZIPファイル自体はアップロードしません。ファイル名も変更しないでください。同じ名前の古いファイルは上書きされます。

アップロード後に古い画面が出る場合は、Safariのタブを閉じてから開き直してください。ホーム画面版は一度削除し、Safariからもう一度「ホーム画面に追加」すると確実です。

この簡易版では、`index.html`、JavaScript、カードデータ、CSS、アイコンがすべて同じ場所に置かれる設計です。

## Ver3の正式ルール基礎

- 先攻・後攻、先攻順のマリガン、初手5枚、ライフ配置
- リフレッシュ、ドロー、DON!!、メイン、エンドの各フェーズ
- 先攻1ターン目はドローなし・DON!!1枚、以降はDON!!最大2枚追加
- 両プレイヤーとも自分の最初のターンは攻撃不可
- リーダーまたはレストのキャラクターを攻撃対象に選択
- ブロックステップ、カウンターステップ、ダメージステップ
- 同じパワーでも攻撃成功、ライフ0へのダメージとデッキ0枚で敗北
- キャラクターエリア5枚、ステージ1枚
- 付与DON!!は自分のターン中に1枚につきパワー+1000
- ライフのトリガーを使用する／手札に加える選択
- 未登録のカード効果は試合を止めず、安全にスキップ

現在のカード名と効果はエンジン確認用デモデータです。カード固有効果は `cards.json` と `effect-engine.js` へ段階的に追加できます。

# Ver3.2 黒黄ティーチ画像デッキ版

## Ver3.3 手札・初手確認表示

手札を縦向きカードの横1列表示へ変更しました。左右にスワイプして全カードを確認でき、従来どおり横へ収納できます。初手確認では「この5枚で始めますか？」とキープ・マリガンの間に5枚の画像を表示します。

プレイヤー側を黒黄ティーチ（OP16-080）の固定50枚デッキに更新しました。ホーム画面の「黒黄ティーチのデッキを見る」から、採用カード・枚数・カード画像を確認できます。盤面と手札も画像表示に対応し、画像を読み込めない場合は自動的に従来の文字カード表示へ戻ります。

カード画像は外部URLから読み込むため、初回表示にはインターネット接続が必要です。現在はゲームの基本操作と汎用効果処理を優先しており、複雑なカード固有効果は未対応でも安全にスキップされます。
